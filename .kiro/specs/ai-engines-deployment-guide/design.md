# Design Document

## Overview

本设计文档描述如何为 Fangyu Code 的四种 AI 编程引擎（Claude Code、OpenAI Codex、Google Gemini、SiliconFlow）编写详细的安装部署指南。

## Architecture

文档将采用统一的结构，每个引擎包含以下章节：
1. 引擎简介
2. 系统要求
3. 安装步骤（跨平台）
4. API Key 获取
5. 环境配置
6. 验证安装
7. 常见问题
