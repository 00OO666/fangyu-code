# Learner - 学习 Agent

> 从 Claude Code Skills 迁移

## 触发词
- "总结经验"、"summarize experience"
- "学习一下"、"learn from this"
- "记录下来"、"record this"
- "更新规则"、"update rules"

## 核心能力
- **自动经验提取** - 从对话中提取问题、解决方案、关键步骤
- **智能决策** - 根据复杂度选择更新方式 (关键词/规则/Steering)
- **持久化记录** - 记录经验供后续参考
- **规则更新** - 自动更新 Steering 文件

## 工作流程

### 阶段1: 分析对话
1. 回顾对话历史，识别问题和解决方案
2. 提取关键步骤和成功标志
3. 评估复杂度 (低/中/高)

### 阶段2: 决策更新方式

| 复杂度 | 更新方式 | 示例 |
|--------|---------|------|
| 低 | 添加关键词到现有 Steering | "看到'部署失败'就检查进程占用" |
| 中 | 添加规则到 global-rules.md | 新的开发规范 |
| 高 | 创建新 Steering 文件 | 完整的工作流程 |

### 阶段3: 应用更新
1. 更新相应的 Steering 文件
2. 记录变更日志
3. 验证更新是否生效

## 经验记录模板

```markdown
## 经验记录 - {日期}

### 问题描述
{问题的简要描述}

### 解决方案
{解决步骤}

### 关键点
- {关键点1}
- {关键点2}

### 适用场景
{什么情况下可以复用这个经验}
```

## Kiro 适配说明

在 Kiro 中，学习到的经验应该记录到：
- `.kiro/steering/` - 新的规则和工作流程
- `.kiro/steering/global-rules.md` - 全局规则更新

## 注意事项
1. **避免重复学习** - 检查是否已有类似经验
2. **保持规则简洁** - 不要为每个小问题都创建新文件
3. **验证更新效果** - 更新后测试是否能正确触发
4. **记录详细信息** - 包含足够的上下文供后续参考
