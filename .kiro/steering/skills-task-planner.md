# Task Planner - 智能任务规划与进度跟踪

> 从 Claude Code Skills 迁移

## 触发词
- "帮我完成下面的任务"
- "请你仔细想一想"
- "这是一个复杂的任务"
- "做一个任务计划表"
- "帮我规划一下"
- "制定升级计划"
- "项目太复杂了帮我拆解"

## 核心能力
- **任务分析** - 自动识别任务类型
- **详细规划** - 生成结构化的任务计划表和依赖关系
- **进度跟踪** - 实时跟踪任务状态和完成进度
- **可视化** - 生成 Mermaid 流程图展示任务依赖
- **智能预测** - 基于历史数据预测完成时间

## 工作流程

### 阶段1: 任务分析
1. 识别任务类型 (Fangyu Code/PbootCMS/前端UI/其他)
2. 分析项目结构和依赖

### 阶段2: 制定计划
1. 拆解任务为子任务
2. 识别任务依赖关系
3. 生成详细任务计划表
4. 创建 Mermaid 流程图
5. 预测完成时间

### 阶段3: 执行跟踪
1. 保存计划到持久化 md 文件
2. 实时更新任务状态
3. 跟踪进度百分比

## 任务计划模板

```markdown
# 任务计划 - {任务名称}

**创建时间**: {YYYY-MM-DD HH:MM:SS}
**项目路径**: {项目路径}
**预计总工时**: {X 小时}
**当前进度**: [████░░░░░░] 40%

## 📊 任务概览

| 总任务数 | 已完成 | 进行中 | 待办 | 完成率 |
|---------|--------|--------|------|--------|
| 12      | 5      | 2      | 5    | 42%    |

## 🎯 任务清单

### 🔴 P0 - 核心任务（必须完成）

#### ⬜ 任务 1: {任务标题}
- **优先级**: P0
- **状态**: ⬜ 待办
- **进度**: [░░░░░░░░░░] 0%
- **预计时间**: 2h
- **依赖**: 无
- **详细步骤**:
  1. [ ] 子步骤 1
  2. [ ] 子步骤 2

### 🟡 P1 - 重要任务（建议完成）
### 🟢 P2 - 优化任务（可选）

## 🚨 问题与风险

| 问题描述 | 影响任务 | 严重程度 | 状态 | 解决方案 |
|---------|---------|---------|------|---------|

## 📝 变更日志

| 时间 | 变更内容 | 操作人 |
|------|---------|--------|
```

## 文件命名规则
- 格式: `{任务名称}_{YYYYMMDD}_{HHMMSS}.md`
- 示例: `Fangyu_Code升级_20251229_143015.md`
- 路径: `E:\Desktop\Claude Code 相关md\`

## 最佳实践

### 何时使用
✅ 任务包含 3+ 个主要步骤
✅ 任务预计耗时 > 1 小时
✅ 需要跨多个文件/模块修改
✅ 涉及多个技术栈

### 进度更新频率
- 🔴 P0 任务：每完成一个子步骤更新
- 🟡 P1 任务：每完成一个任务更新
- 🟢 P2 任务：批量更新
