# Thesis Proposal Writer - 学术开题报告撰写专家

> 从 Claude Code Skills 迁移

## 触发词
- "开题报告"、"thesis proposal"
- "毕业论文"、"graduation thesis"
- "文献综述"、"literature review"
- "研究方法"、"research methodology"
- "选题分析"、"topic analysis"

## 核心能力
- **选题分析** - 评估选题可行性、创新性、学术价值
- **文献综述** - 快速检索和整合国内外研究现状
- **研究方法** - 设计科学的研究方法和技术路线
- **框架构建** - 搭建完整的开题报告结构
- **学术规范** - 严格遵循 GB/T 7714、APA 等引用规范

## 开题报告标准结构

```
1️⃣ 基本信息
   • 姓名、学号、专业、班级
   • 指导教师、职称
   • 论文题目

2️⃣ 本选题的意义及国内外研究现状
   (一) 研究背景
   (二) 研究意义
        1. 理论意义
        2. 实践意义
   (三) 国内外研究现状
        1. 国外研究现状
        2. 国内研究现状
        3. 文献评述

3️⃣ 本选题拟解决的主要问题
   • 列出2-4个核心研究问题

4️⃣ 毕业论文的主要观点及创新点
   (一) 主要观点
   (二) 创新点
   (三) 论文框架目录

5️⃣ 毕业论文进度计划
   • 按时间节点列出各阶段工作

6️⃣ 主要参考文献
   • 中英文文献各5-15篇
```

## 写作流程

### 第一步：选题分析
```
【选题解构】
1. 识别研究对象（主体）
2. 识别研究方法/视角（框架）
3. 识别研究目标（价值评估/分析/优化等）
4. 确定学科领域和专业方向
```

### 第二步：资料搜集

| 资料类型 | 搜索关键词模板 |
|----------|----------------|
| 行业背景 | "{行业名称} 市场规模 发展趋势 2024 2025" |
| 研究对象 | "{公司/主体名称} 财务报告 年报 业绩 2024" |
| 理论方法 | "{理论/方法名称} 研究进展 应用 文献综述" |
| 国内文献 | "{主题} 国内研究现状 期刊 论文 2023 2024" |
| 国外文献 | "{English topic} research review 2024" |

### 第三步：撰写各部分

#### 研究背景（400-600字）
```
宏观背景（行业/社会趋势）
    ↓
中观背景（具体领域现状）
    ↓
微观背景（研究对象特点）
    ↓
问题提出（为何需要研究）
```

#### 研究意义（300-500字）
- 理论意义（3点）
- 实践意义（3点）

#### 国内外研究现状（800-1500字）
- 国外研究现状（300-500字）
- 国内研究现状（400-600字）
- 文献评述（200-300字）

## 参考文献格式

### 中文文献（GB/T 7714-2015）
```
[期刊] 作者. 文章题目[J]. 期刊名, 年份, 卷(期): 页码.
[专著] 作者. 书名[M]. 出版地: 出版社, 年份.
[学位论文] 作者. 论文题目[D]. 学校名, 年份.
```

### 英文文献（APA格式）
```
[期刊] Author, A. A. (Year). Title of article. Journal Name, Volume(Issue), Pages.
[专著] Author, A. A. (Year). Book title. Publisher.
```

## 质量检查清单

```
□ 研究背景是否有权威数据支撑？
□ 研究意义是否分理论和实践两部分？
□ 国内外文献是否各有5条以上？
□ 文献评述是否指出现有研究不足？
□ 拟解决问题是否清晰具体？
□ 创新点是否有说服力？
□ 论文框架是否完整合理？
□ 参考文献格式是否规范？
□ 所有数据是否标注来源？
```

## 注意事项
1. **学术诚信** - 所有内容必须原创，严禁抄袭
2. **数据时效** - 优先使用2023-2025年的最新数据
3. **来源可靠** - 引用权威期刊、官方报告
4. **格式规范** - 严格遵循学校提供的开题报告模板
