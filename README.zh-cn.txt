## 🎬 Quick Start

### 📦 Download & Install

Download the latest version from [Releases](https://github.com/00OO666/fangyu-code/releases):

| Platform | Download | Description |
|------|------|------|
| **Windows** | `.msi` / `.exe` | MSI installer recommended |
| **macOS** | `.dmg` | Apple Silicon supported |
| **Linux** | `.AppImage` / `.deb` | AppImage recommended |

### ⚙️ Prerequisites

1. **Install Claude Code CLI** (Required)
   ```bash
   # Verify installation
   claude --version
   ```

2. **(Optional) Install Gemini CLI**
   ```bash
   npm install -g @anthropic-ai/claude-code
   gemini --version
   ```

### 🚀 First Use

1. Launch Fangyu Code
2. Select your project directory
3. Choose AI engine (Claude/Codex/Gemini)
4. Start chatting!

## 📖 User Guide

### Prompt Queue (Killer Feature)

| Action | Description |
|------|------|
| **Enter to Send** | Sends immediately if AI is idle; automatically queues if AI is busy |
| **Queue Button** | "Queue" button in the bottom right (visible when AI is working) |
| **Revoke & Edit** | Click revoke in the queue panel to return the instruction to the input box |
| **Jump-the-Queue** | Click ⚡ icon to send instant guidance (without interrupting AI) |
| **Bundle Send** | Switch to "Bundle" mode to merge multiple instructions |

### Shortcuts

| Shortcut | Function |
|--------|------|
| `Ctrl+Enter` | Send message |
| `Shift+Tab` | Switch Plan Mode |
| `Ctrl+Tab` | Switch session tabs |
| `Ctrl+W` | Close current session |
| `Ctrl+Shift+C` | Open Canvas preview |
| `Ctrl+Shift+T` | Open usage statistics charts |

### Plan Mode (Read-only Mode)

- Code exploration and analysis
- Solution design and evaluation
- No file modification, no command execution

> For detailed architecture documentation, please refer to [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

```
┌─────────────────────────────────────────────────────┐
│                   Fangyu Code                        │
├─────────────────┬─────────────────┬─────────────────┤
│   React Frontend │   Tauri Bridge   │    Rust Backend    │
│                 │                 │                 │
│ • React 18      │ • IPC Comm       │ • Triple Engine Mgmt│
│ • TypeScript    │ • Event Stream   │ • SQLite Storage    │
│ • Tailwind CSS  │ • Type Safety    │ • MCP Protocol     │
│ • Framer Motion │                 │ • Translation Svc    │
└─────────────────┴─────────────────┴─────────────────┘
                           │
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
```

## 🛠️ Build from Source

```bash
# Clone repository
git clone https://github.com/00OO666/fangyu-code.git
cd fangyu-code

# Install dependencies
npm install

# Development mode
npm run tauri dev

# Build production version
npm run tauri build
```

**Build Requirements**:
- Node.js 18+
- Rust 1.70+
- Windows: WebView2 Runtime
