## 🧪 验证步骤

### 步骤 1：启动开发模式

```bash
cd F:/Fangyu-Code-Dev
npm run tauri:dev
```

### 步骤 2：打开浏览器控制台

按 `F12` 打开开发者工具，切换到 Console 标签。

### 步骤 3：检查监控启动日志

在控制台中查找以下日志：

```
[ConsoleMonitor] 已启用，正在监控 console.error 和 console.warn
```

**✅ 如果看到此日志**：Console 监控已成功启动

**❌ 如果没有看到**：检查是否在开发模式（`import.meta.env.DEV` 应为 true）

### 步骤 4：测试错误拦截

在浏览器控制台中手动触发错误：

```javascript
console.error("测试错误：这是一个测试错误");
console.warn("测试警告：这是一个测试警告");
```

**预期结果**：
- 控制台中仍然显示这些错误/警告（因为 `showOriginal: true`）
- 错误被监控系统拦截并记录

### 步骤 5：检查错误监控面板

在 Fangyu Code 界面中查找错误监控面板：

**可能的位置**：
- 右下角浮动按钮
- 底部状态栏
- 侧边栏

**预期内容**：
- 显示刚才触发的测试错误和警告
- 显示错误数量统计
- 提供清除按钮

### 步骤 6：测试实际场景

发送一条提示词到 Claude，观察：

1. **会话统计是否正确**
   - 检查 token 计费是否准确
   - 不应该出现重复计费

2. **是否有去重日志**
   - 如果有重复消息，控制台应显示：
   ```
   [SessionCost] 🔧 去重: 原始 X 条 → 去重后 Y 条 (移除 Z 条重复)
   ```

3. **错误监控是否捕获异常**
   - 如果有任何错误，应该在监控面板中显示

## 🐛 常见问题

### 问题 1：看不到监控启动日志

**可能原因**：
- 不在开发模式（生产构建不会启用监控）
- useConsoleMonitor 未正确导入

**解决方法**：
```bash
# 确保使用开发模式
npm run tauri:dev

# 检查 import.meta.env.DEV
console.log("DEV mode:", import.meta.env.DEV);
```

### 问题 2：错误监控面板不显示

**可能原因**：
- ErrorMonitorPanel 组件有 CSS 问题
- 组件被其他元素遮挡

**解决方法**：
1. 检查浏览器控制台是否有 React 错误
2. 使用浏览器开发者工具检查 DOM 中是否有 ErrorMonitorPanel 元素
3. 检查 CSS z-index 是否正确

### 问题 3：TypeScript 编译错误

**可能原因**：
- 直接运行 `tsc` 不会使用项目配置

**解决方法**：
- 使用 Vite 构建：`npm run build`
- 或使用开发模式：`npm run tauri:dev`
- 不要直接运行 `tsc`
