# 语音输入功能使用指南

## 功能概述

Fangyu Code 现已集成闪电说语音识别服务，支持中英文混合语音输入。

## 使用方法

### 方法 1：点击按钮
1. 在聊天输入框右侧找到**麦克风图标**按钮
2. 点击开始录音（按钮会变红并闪烁）
3. 说出你想输入的内容
4. 再次点击停止录音
5. 识别结果会自动添加到输入框中

### 方法 2：快捷键
- 按 `Ctrl+Shift+V` 开始录音
- 再次按 `Ctrl+Shift+V` 停止录音

## 配置 API Key

首次使用需要配置闪电说 API Key：

1. 打开设置页面
2. 找到"语音输入"设置项
3. 输入你的闪电说 API Key
4. 保存设置

**获取 API Key：**
访问 [闪电说官网](https://www.flashspeech.com/) 注册并获取 API Key

## 功能特点

- ✅ 支持中英文混合识别
- ✅ 实时显示录音时长
- ✅ 识别结果自动添加到输入框
- ✅ 支持快捷键操作
- ✅ 录音状态可视化（红色闪烁）

## 注意事项

1. **麦克风权限**：首次使用时浏览器会请求麦克风权限，请允许
2. **网络连接**：需要网络连接才能使用语音识别服务
3. **API Key**：确保已正确配置闪电说 API Key
4. **录音时长**：建议每次录音不超过 60 秒

## 故障排除

### 无法开始录音
- 检查麦克风权限是否已授予
- 检查麦克风是否正常工作
- 尝试刷新页面

### 识别失败
- 检查网络连接
- 确认 API Key 是否正确
- 检查闪电说服务是否正常

### 识别结果不准确
- 尽量在安静环境中录音
- 说话清晰，语速适中
- 避免背景噪音

## 技术实现

- **语音识别服务**：闪电说 API
- **音频格式**：WebM
- **支持语言**：中文、英文（混合）
- **录音方式**：浏览器 MediaRecorder API
