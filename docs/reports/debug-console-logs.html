🔍 Fangyu Code 控制台日志收集器

这个页面会帮助你收集 Fangyu Code 的控制台日志。

使用说明：

  1. 在 Fangyu Code 中打开开发者工具（F12）
  2. 在 Console 标签中，粘贴以下代码并按 Enter：
// 收集所有 useSessionStream 相关的日志 const logs = []; const originalLog = console.log; const originalError = console.error; const originalWarn = console.warn; console.log = function(...args) { const message = args.map(a => typeof a === 'object' ? JSON.stringify(a) : String(a)).join(' '); if (message.includes('[useSessionStream]') || message.includes('checkForActiveSession')) { logs.push({ type: 'log', message, timestamp: new Date().toISOString() }); } originalLog.apply(console, args); }; console.error = function(...args) { const message = args.map(a => typeof a === 'object' ? JSON.stringify(a) : String(a)).join(' '); if (message.includes('[useSessionStream]') || message.includes('checkForActiveSession')) { logs.push({ type: 'error', message, timestamp: new Date().toISOString() }); } originalError.apply(console, args); }; console.warn = function(...args) { const message = args.map(a => typeof a === 'object' ? JSON.stringify(a) : String(a)).join(' '); if (message.includes('[useSessionStream]') || message.includes('checkForActiveSession')) { logs.push({ type: 'warn', message, timestamp: new Date().toISOString() }); } originalWarn.apply(console, args); }; console.log('✅ 日志收集器已启动！现在重新打开会话，然后运行 window.showLogs() 查看收集到的日志'); window.showLogs = function() { console.log('=== 收集到的日志 ==='); logs.forEach(log => { console.log(`[${log.timestamp}] [${log.type}] ${log.message}`); }); console.log('=== 日志结束 ==='); return logs; }; window.clearLogs = function() { logs.length = 0; console.log('✅ 日志已清除'); };

步骤：

  1. 复制上面的脚本
  2. 在 Fangyu Code 的控制台中粘贴并运行
  3. 重新打开一个会话（或刷新页面）
  4. 在控制台中运行 window.showLogs() 查看日志
  5. 将日志复制给我分析

快速过滤方法：

或者，你也可以直接在控制台的 Filter 输入框中输入：

useSessionStream

这样只会显示包含 "useSessionStream" 的日志。
