2. 点击左下角 **⚙️ 设置**
3. 找到 **API 配置** 选项卡

3. 点击 **验证** 按钮
4. 看到 ✅ 验证成功 后，点击 **保存**

## 💡 使用技巧

### 技巧 1：选择合适的模型

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 日常问答 | gpt-4o-mini | 便宜、快速 |
| 复杂编程 | claude-3.5-sonnet | 代码能力强 |
| 长文档 | gemini-1.5-pro | 上下文窗口大 |
| 深度思考 | claude-3-opus | 推理能力最强 |

### 技巧 2：控制成本

1. **简单问题用小模型**：gpt-4o-mini 比 gpt-4o 便宜 10 倍
2. **关注 Token 统计**：每次对话后查看消耗
3. **精简提示词**：不要复制粘贴大段无关内容

### 技巧 3：处理错误

| 错误信息 | 解决方法 |
|----------|----------|
| API 密钥无效 | 检查密钥是否正确复制，有无多余空格 |
| 连接超时 | 检查网络，或稍后重试 |
| 速率限制 | 等待 1 分钟后重试 |
| 余额不足 | 充值 API 账户 |

## ❓ 常见问题

### Q: HiAPI 是什么？安全吗？

HiAPI 是一个 AI API 中转服务，它：
- 聚合多个 AI 提供商的 API
- 提供统一的接口格式
- 国内可直连

安全性：你的对话内容会经过 HiAPI 服务器转发到 AI 提供商。如果对隐私有顾虑，可以直接使用官方 API。

### Q: 为什么要配置 API？之前不是可以直接用吗？

之前的版本使用的是模拟数据（Mock），不是真正的 AI 响应。v2.5.0 升级为真实 API 调用，需要你提供自己的 API 密钥。

### Q: API 密钥会被泄露吗？

不会。API 密钥存储在你本地的 localStorage 中，不会上传到任何服务器。

### Q: 费用怎么算？

费用由 AI 提供商收取，Fangyu Code 不收取任何费用。具体价格参考各提供商的定价页面。
