## 🎯 如何测试

### 1. 启动应用
```bash
npm run tauri dev
```

### 2. 测试已实现功能

#### 语音输入
1. 打开设置 → 配置闪电说 API Key
2. 在聊天输入框点击麦克风按钮或按 Ctrl+Shift+V
3. 说话后再次点击停止
4. 验证识别结果是否添加到输入框

#### V3.0 功能中心
1. 按快捷键 `0` 或点击侧边栏"V3.0 功能"
2. 点击"LSP 功能可视化"卡片
   - 验证代码编辑器是否显示
   - 测试代码智能提示
3. 点击"Diff 预览器"卡片
   - 验证 diff 视图是否显示
   - 测试 Accept/Reject 按钮
4. 点击"内置终端"卡片
   - 验证终端是否显示
   - 测试命令执行
5. 点击其他 6 个卡片
   - 验证是否显示"开发中"占位页面
