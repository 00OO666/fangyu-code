# 字体文件下载说明

本项目需要以下字体文件，请下载并放置到对应目录：

## 1. Inter
- 下载地址: https://github.com/rsms/inter/releases
- 文件: Inter-VariableFont.woff2
- 放置位置: `src/assets/fonts/Inter/`

## 2. Geist Sans
- 下载地址: https://github.com/vercel/geist-font/releases
- 文件: GeistVF.woff2
- 放置位置: `src/assets/fonts/Geist/`

## 3. DM Sans
- 下载地址: https://fonts.google.com/specimen/DM+Sans
- 文件: DMSans-VariableFont.woff2
- 放置位置: `src/assets/fonts/DMSans/`

## 4. 思源黑体 / Noto Sans CJK SC
- 下载地址: https://github.com/googlefonts/noto-cjk/releases
- 文件: NotoSansSC-VariableFont.woff2
- 放置位置: `src/assets/fonts/NotoSansSC/`

## 5. 阿里巴巴普惠体
- 下载地址: https://www.alibabafonts.com/#/font
- 文件: Alibaba-PuHuiTi-Regular.woff2, Alibaba-PuHuiTi-Bold.woff2
- 放置位置: `src/assets/fonts/AlibabaPuHuiTi/`

## 6. 霞鹜文楷 / LXGW WenKai
- 下载地址: https://github.com/lxgw/LxgwWenKai/releases
- 文件: LXGWWenKai-Regular.woff2
- 放置位置: `src/assets/fonts/LXGWWenKai/`

## 注意事项

1. 所有字体文件应该使用 woff2 格式（最佳压缩率）
2. 优先使用可变字体（Variable Font）以减小文件大小
3. 确保字体文件的授权允许商业使用
4. 字体文件总大小应控制在 50MB 以内

## 临时方案

在字体文件下载完成前，系统将使用 Google Fonts CDN 作为备选方案。
