# Task Planner - 智能任务规划器

## 概述

智能任务规划器，帮助将复杂的开发需求分解为可执行的任务列表。

核心能力：
- **需求分析** - 理解用户意图，识别关键目标
- **任务分解** - 将大任务拆分为原子任务
- **依赖分析** - 识别任务间的依赖关系
- **并行识别** - 找出可并行执行的任务
- **进度跟踪** - 实时更新任务状态

## 触发条件

当用户提到以下关键词时自动触发：
- "帮我规划" / "make a plan"
- "任务拆解" / "decompose task"
- "做个计划" / "create plan"
- "分解任务" / "break down"
- "项目规划" / "project planning"

## 工作流程

### 步骤 1: 需求收集

询问用户以下信息：
```
请描述你要完成的任务：
1. 最终目标是什么？
2. 有哪些约束条件？（时间、技术栈、资源等）
3. 是否有已完成的部分？
```

### 步骤 2: 任务分解

根据需求生成任务列表：

```json
{
  "tasks": [
    {
      "id": "task-1",
      "name": "任务名称",
      "description": "详细描述",
      "priority": "high|medium|low",
      "estimatedTime": "30min",
      "dependencies": [],
      "status": "pending"
    }
  ]
}
```

### 步骤 3: 依赖分析

识别任务间的依赖关系，生成 DAG 图：

```
task-1 ──→ task-3 ──→ task-5
              ↘
task-2 ──→ task-4 ──→ task-6
```

### 步骤 4: 执行建议

提供执行顺序建议：
1. 关键路径任务优先
2. 可并行任务同时进行
3. 低优先级任务延后

### 步骤 5: 进度跟踪

任务完成后更新状态：
- ⬜ pending - 待开始
- 🔄 in-progress - 进行中
- ✅ completed - 已完成
- ❌ failed - 失败
- ⏸️ blocked - 阻塞

## 输出格式

### Markdown 任务列表

```markdown
## 任务计划: [项目名称]

### 📋 任务列表

| # | 任务 | 优先级 | 预估时间 | 依赖 | 状态 |
|---|------|--------|----------|------|------|
| 1 | 初始化项目 | 🔴 高 | 10min | - | ⬜ |
| 2 | 设计数据结构 | 🔴 高 | 30min | 1 | ⬜ |
| 3 | 实现核心逻辑 | 🟡 中 | 2h | 2 | ⬜ |

### 🔀 并行组
- 组 A: 任务 3, 4 可并行
- 组 B: 任务 5, 6, 7 可并行

### ⏱️ 预估总时间: 4.5 小时
```

## 注意事项

1. **粒度控制** - 单个任务不超过 2 小时，否则继续拆分
2. **依赖最小化** - 减少任务间依赖，提高并行度
3. **风险识别** - 标注高风险任务，准备备选方案
4. **灵活调整** - 执行过程中可动态调整计划

## 最佳实践

### 任务命名
✅ 好的：`实现用户登录 API`
❌ 差的：`做登录`

### 时间估算
- 简单任务：15-30 分钟
- 中等任务：1-2 小时
- 复杂任务：拆分为多个子任务

### 优先级判断
- 🔴 高：阻塞其他任务、核心功能
- 🟡 中：重要但不紧急
- 🟢 低：可延后、优化类
